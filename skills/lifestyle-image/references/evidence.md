# 已有实验与适用边界

2026-11-05 的三轮实验使用原帧、人物参考、商品和已有垫图，主要题材为服装人像，另含杯子、鞋及三个住宅空场景。结论是小样本视觉观察，没有盲评或视频生成验证。

- 人物参考 2 对 2：原生产提示词不动，仅换去精修人物图，眼妆减轻，摆拍感仍在。支持改变上游参考，不支持把所有人强制素颜。
- 原片说话帧＋去精修人物、9:16 车内自拍，两条组合各独立重复一次，观感改善；组合同时改了多项，不能分摊因果或推算成功率。不能把更换源片时点当成无损修改。
- 普通人物方案曾生出三只手；简化同时发生的动作后两次结果正常。镜自拍曾出现标识方向错误，局部编辑纠正。不能把这些当作普遍生成禁令。
- 旧手机和失败快照有生活感，同时会糊脸和丢失商品细节。JSON 与 3:4 各只有有限对照，未证明稳定优于其他写法或 9:16。
- 三张好图继续经过 Nano Banana Pro 编辑→内置生图增强，没有一致胜过直接增强；出现皮肤泛红、纹理过强、新增灰内搭。内置工具未暴露确切版本，这不是对某个 GPT Image 版本的严格复现。
- 实际轻后期改动可控但收益有限；中度开始损失细节。轻档试过长边≤1600、Gaussian blur 0.22px、8-bit 亮度噪声σ0.8/色噪σ0.15、JPEG91；它是可调整样本，不是万能参数或默认步骤。
- 圣诞客厅、美国农舍、纽约公寓的空场景体现了具体空间和照明描述的作用；尚未验证人像合成后的透视、受光与视频一致性。

本公开包提供方法与经验摘要，仓库 README 另附精选 AI 实验结果与对比图；不包含原始人物照片、商品参考素材及完整实验记录。以上是作者的探索性观察，不是可独立复核的公开基准或成功率承诺；执行本技能不依赖这些未公开材料。
